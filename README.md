## Projects

**[FinScribe](https://github.com/Rishabh200729/FinScribe)**
Self-learning financial transaction categorizer. A two-stage Dynamic Exemplar Engine (zero-shot cosine similarity + few-shot matching) on Sentence Transformer embeddings — macro F1 above 0.90, runs fully local via FastAPI + Streamlit.

**[Smart Finance Tracker](https://github.com/Rishabh200729/Finance-Tracker)**
Full-stack financial management app built with Next.js, TypeScript, PostgreSQL, and the Gemini API.

**[Events Near Me](https://github.com/Rishabh200729/EventsNearMe)**
Discover local events and activities happening around you in real time.

**[MedVault AI](https://github.com/Rishabh200729/MEDVAULT)**
Centralized medical identity ecosystem with AI OCR, role-based access, and emergency QR codes.

**Traffic Monitoring — YOLOv8**
Real-time traffic monitoring system built during an internship at Thapar Institute of Engineering and Technology.
